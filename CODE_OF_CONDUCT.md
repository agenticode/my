# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

It applies to the issues, pull requests and review comments of this repository, and to anyone who speaks for the project elsewhere.

What it asks, in short:

- Be respectful. Criticise the code, the data and the argument, and leave the person out of it.
- Accept that others see a problem differently, and say what you would change and why.
- No harassment, no insults, no sexual language or attention, no publishing of private information of others.

To report a problem, write to the address on the profile of the repository owner (https://github.com/agenticode). Reports are kept confidential. The maintainers decide what follows, from a request to change a comment to a ban from the repository, as the Covenant describes.
